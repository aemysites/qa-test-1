# table-bordered

Custom **table** block. Purpose: Data table with a full cell grid and a bold header row; scrolls horizontally on narrow screens.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: First row: header cells (bold). Following rows: one data row each, one cell per column; empty cells are allowed.
