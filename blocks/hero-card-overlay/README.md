# hero-card-overlay

Custom **hero** block. Purpose: Top-of-page welcome hero: full-width photo with a boxed card (heading, intro, CTA) overlaid on the right on desktop; stacks image then card on mobile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: background image; Row 2: heading, paragraph(s), CTA link.
