# cards-event

Custom **cards** block. Purpose: Grid of event items (3 per row on desktop): image, event name heading, bold-label Date and Time lines, optional description. Not clickable.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per event: cell 1 image (optional), cell 2 heading (H3 event name), then paragraphs starting with a bold label such as **Date:** and **Time:**, then an optional description.

## Supported variations

No variations.
