# cards-linked-arrow

Custom **cards** block. Purpose: Grid of image-top cards (3 per row on desktop), each with a linked title, short description and a trailing arrow; whole card is clickable.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card: cell 1 image, cell 2 linked title + description; Options in the block name: Cards Linked Arrow (dark | horizontal | off-white | highlight); the image cell may be left empty for text-only related-page cards.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |
| Horizontal | `horizontal` |
| Off White | `off-white` |
| Highlight | `highlight` |
