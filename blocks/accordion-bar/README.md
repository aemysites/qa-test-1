# accordion-bar

Custom **accordion** block. Purpose: Expandable sections shown as stacked grey title bars with a chevron; each opens a rich-text panel. Use for entry pathways, policies and program lists.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item: cell 1 title (plain text), cell 2 panel content (paragraphs, headings, lists, links, tables).
