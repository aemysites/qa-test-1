# embed-iframe

Custom **embed** block. Purpose: Responsive 16:9 iframe for a Brightcove video (bcove.video short link) or a Google Maps embed URL, with a keyboard skip link; loads when scrolled into view, or on click when a poster image is authored.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row, one cell: the embed URL as a link (https://bcove.video/... or https://www.google.com/maps/embed/v1/place?...); optionally a poster image in the same cell for click-to-load.

## Supported variations

No variations.
