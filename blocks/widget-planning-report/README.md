# widget-planning-report

Custom **widget** block. Purpose: Bulleted list of the school's published annual reports or school excellence plans (PDF links with year, name, type and size), loaded live from the NSW DoE school-plan-report API.

## Authoring (Document Authoring)

Model: `configuration`

Key/value rows (label in the first cell, value in the second): Key/value rows: reporttype | report (annual reports) or plan (school excellence plans); schoolcode | 8504; optional recentreports | <number>; Alternative (widget convention): one cell with a link /widgets/planningreporting.html?reporttype=report&schoolcode=8504.

## Supported variations

No variations.
