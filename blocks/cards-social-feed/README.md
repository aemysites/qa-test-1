# cards-social-feed

Custom **cards** block. Purpose: Social post cards: post image, truncated linked excerpt, arrow and network icon; 3-column grid on desktop, horizontal swipe carousel on mobile.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per post: cell 1 image, cell 2 linked excerpt.
