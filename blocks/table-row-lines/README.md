# table-row-lines

Custom **table** block. Purpose: Light data table with horizontal row rules only; the first row is a bold header unless the no-header option is set (name lists, honour rolls).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: First row: header cells (omit by naming the block Table Row Lines (no-header)). Following rows: one data row each, one cell per column; empty cells are allowed.

## Supported variations

| Variation | Option class |
| --- | --- |
| No Header | `no-header` |
