# carousel-gallery

Custom **carousel** block. Purpose: Photo gallery slider: each slide is an image with a caption bar; 2 slides per view on tablet and desktop, 1 on mobile, with prev/next buttons and dot pagination.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide: cell 1 image, cell 2 caption text.

No variations.
